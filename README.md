# «Голову с плеч» by Mikerov — лендинг мастерской

Одностраничный сайт: один файл `index.html` (стили и скрипты внутри) + папка `images/`.

## Как посмотреть

Откройте `index.html` в браузере. Для публикации загрузите `index.html` и папку `images/`
на любой хостинг (GitHub Pages, Netlify, обычный хостинг) — сборка не нужна.

## Как редактировать

| Что поменять | Где искать в `index.html` |
| --- | --- |
| Цвета, шрифты | блок `:root` в начале `<style>` («НАСТРОЙКИ ДИЗАЙНА») |
| Ссылки на запись, Telegram, телефон, почту, соцсети | объект `SITE` в начале `<script>` внизу файла («НАСТРОЙКИ САЙТА») |
| Тексты | прямо в разметке, секции отмечены комментариями `═══ СЕКЦИЯ: … ═══` |
| Цены | таблицы в секции «УСЛУГИ И ЦЕНЫ»: колонки `l1`–`l4` — уровни мастеров, `na` — услуга не выполняется |
| Мастера | секция «КОМАНДА»: карточка + подробное описание в `<template>` |
| Фото | папка `images/` — замените файл с тем же именем |

## Структура страницы

1. Главный экран — слоган, онлайн-запись (YClients) и Telegram
2. О нас — арт-директор Дмитрий Микеров, философия, преимущества, атмосфера
3. Работы — галерея с просмотром во весь экран
4. Услуги и цены — 6 категорий, цены по уровням мастеров
5. Команда — 9 мастеров, подробности в окне
6. Отзывы — с Яндекс Карт
7. Контакты — адрес, режим работы, телефон, соцсети, карта Яндекса

Сайт адаптирован под телефон, планшет и компьютер, учитывает настройку
«уменьшить движение» (prefers-reduced-motion) и работает без JavaScript
(без анимаций и вкладок).
